# Bad Moon Rising rule-fidelity matrix

Status: implementation audit for `codex/bmr-rule-fidelity`  
Rules baseline: official Blood on the Clocktower wiki, checked 2026-07-20  
Scope: the 25 base Bad Moon Rising characters only

## Reading the matrix

- **C — local contract:** the mandatory clause is represented in `scripts/roles/bmr.js` and covered by either the focused contract or an existing shared contract.
- **P — explicit policy:** the official ability grants Storyteller discretion. The simulator policy is named, reproducible, and logged; it is not presented as an official rule.
- **I — interface request:** full fidelity needs a shared engine seam outside this change's exclusive edit scope. The exact request is linked; no local duplicate was added.
- A row can have more than one marker. This document is an audit ledger, not a capability-maturity declaration.

Global official semantics apply to every row: dead, drunk, or poisoned characters have no ability; drunk/poisoned information may be legal false information; rule information remains true. Sources: [Abilities](https://wiki.bloodontheclocktower.com/Abilities), [States](https://wiki.bloodontheclocktower.com/States), and [Rules Explanation](https://wiki.bloodontheclocktower.com/Rules_Explanation).

## Official night order

The exported `BMR_NIGHT_ORDER` constant is the auditable official-order oracle used by the focused contract.

- First night: Lunatic → Sailor → Courtier → Godfather → Devil's Advocate → Pukka → Grandmother → Chambermaid.
- Other nights: Sailor → Innkeeper → Courtier → Gambler → Devil's Advocate → Lunatic → Exorcist → Zombuul → Pukka → Shabaloth → Po → Assassin → Godfather → Professor → Gossip → Tinker → Moonchild → Grandmother → Chambermaid.

The module records actual own-ability wakes in `wokeTonightByPlayerId`; Chambermaid reads those receipts after all night actions, rather than inferring wakes from a static role list. Priority Demon continuations, Assassin, Gossip, Tinker, Moonchild, Grandmother, and Chambermaid now re-check state at their ordered local callbacks. The frozen monolithic runner and existing shared contracts still require Professor and Godfather to resolve before the Demon; fully dispatching the exported order is tracked in [#12](https://github.com/YuriHKj/botc-solo-simulator/issues/12). The matrix does not claim that remaining mismatch is complete.

## Deterministic policy registry

The runtime exports `BMR_STORYTELLER_POLICIES` and `BMR_AGENT_POLICIES`. A policy entry must contain an id, its decision rule, and its determinism basis. The focused contract rejects probability-shaped policy text. Storyteller policies currently cover Grandmother selection, Sailor and Innkeeper drunkenness, Pacifist, Tinker, Shabaloth regurgitation, Gossip parsing fallback, and Gossip death targeting.

No shared engine, action bridge, viewmodel, capability configuration, package script, or existing test was edited. Remaining mandatory gaps are tracked as:

These requests deliberately prevent the BMR module from duplicating engine-owned validation, lifecycle, setup, or pending-action logic.
